# Data sources and terms

| Source | Endpoint host | Terms / notes |
|---|---|---|
| SAM.gov Opportunities | api.sam.gov | Requires your own free API key; subject to SAM.gov API rate limits and terms. The tool caches and spaces requests. |
| USAspending | api.usaspending.gov | Public U.S. Government data, no key. Used for expiring contracts and incumbent lookups. |
| GSA Acquisition Gateway forecast | acquisitiongateway.gov | Public forecast data served as an **undocumented JSON feed**; it may change or disappear. Be gentle with page limits. |
| GAO reports | www.gao.gov (RSS) | Public; stored as market signals only. |

U.S. Government works are generally not subject to copyright, but each site has its own terms of use and rate limits; you are responsible for complying with them. Nothing in this repository is a copy of provider data except **synthetic** sample data.

Estimated dates/values (agency forecasts, derived release dates from contract expirations) are labelled as such and are **not** government commitments.
